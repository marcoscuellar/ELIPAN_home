# ELIPAN Group website

The home page for [elipangroup.com](https://www.elipangroup.com/).

- `index.html`: the page (plain HTML, no build step)
- `img/`: photos and the link-preview image
- `api/contact.js`: the contact form, sent by email through Resend (needs `RESEND_API_KEY` in Vercel)
- `robots.txt`, `sitemap.xml`, `llms.txt`: for search engines and AI tools
